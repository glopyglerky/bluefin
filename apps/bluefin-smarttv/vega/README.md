# Bluefin Vega native candidate

Official Vega 2.0 template configuration, native VideoPlayer/surface lifecycle and an upstream Apache-2.0 hls.js adapter. See `docs/bluefin/vega-build.md` at the repository root for exact tooling, build steps, observed package qualification and runtime limits.

No installed playback, HLS/live parity or public release acceptance is claimed. SDK and native runtime dependencies remain separately licensed and outside source. No confidential adaptive-player wrapper is included.
