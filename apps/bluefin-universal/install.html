Install Bluefin

Keep the original QR code. After installing Bluefin, scan it again to use the invitation. If you already started pairing, finish on the device where you started.

Continue in the browser
Add the web app to iPhone or iPad

Open Bluefin in Safari, choose Share, then Add to Home Screen. Turn on Open as Web App if Safari offers it, then tap Add. Open Bluefin from its new icon and scan the original QR again before starting the connection.

Install the web app on Android or a computer

Open Bluefin in your browser and choose Install app or Add to Home screen from its menu if available. Open the installed app and scan or paste the original invitation before starting the connection.

Installing the web app does not transfer a connection from this browser tab. A remembered device stays with the browser storage that created it.
